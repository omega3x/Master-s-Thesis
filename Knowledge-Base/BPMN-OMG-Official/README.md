# База знаний: OMG BPMN 2.0 (bpmn.org)

Конспекты по официальной спецификации **Business Process Model and Notation (BPMN)**, поддерживаемой Object Management Group.

## Источник

- Сайт: https://www.bpmn.org/ (перенаправляет на OMG)
- Спецификация: https://www.omg.org/spec/BPMN/2.0.2/
- Актуальная формальная версия: **BPMN 2.0.2** (принята в январе 2014)
- Международный стандарт: **ISO/IEC 19510:2013** (на основе OMG BPMN 2.0)

## Важно

Эта папка **не является** копией PDF-спецификации OMG (~500 страниц). Это структурированные учебные заметки по ключевым разделам: Scope, Overview, Elements, Conformance, Process types.
